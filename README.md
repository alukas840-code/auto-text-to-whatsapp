# WhatsApp Scheduler (Android)

Приложение для Android (актуальный стек: Kotlin + Jetpack Compose + Room + WorkManager), которое позволяет на телефоне:

- добавить текст сообщения,
- указать одну или несколько групп (строкой через запятую),
- задать дату и время отправки,
- включать/выключать отправку для каждого задания.

## Важно о WhatsApp

Официально WhatsApp не предоставляет публичного API для автоматической отправки сообщений в группы из обычного клиентского приложения.
В этом MVP используется запуск deep-link `wa.me` с предзаполненным текстом в указанное время.

Это означает:
- приложение открывает WhatsApp c текстом,
- финальное подтверждение отправки может потребоваться пользователю,
- для полноценной «авто-отправки без касаний» обычно нужны дополнительные механизмы (например, Accessibility Service) и строгая проверка на соответствие политике Google Play и WhatsApp.

## Сборка

1. Откройте проект в Android Studio (Hedgehog/Koala или новее).
2. Установите Android SDK 35.
3. Синхронизируйте Gradle и запустите `app` на устройстве.

## Что уже реализовано

- Compose UI для управления расписанием на телефоне.
- Локальное хранение расписаний в Room.
- Планирование задач через WorkManager.
- Поддержка нескольких групп в одной задаче (CSV-строка).
